# Shaida Muhammad Sherpao — Portfolio

## Files
- `index.html` — responsive portfolio, search-friendly metadata, Schema.org Person data, full CV content, projects, and publications.
- `images/shaida-muhammad-sherpao.jpg` — profile image (square aspect ratio, sized responsively to avoid distortion on mobile).
- `Shaida-Muhammad-Resume-2026.pdf` — the supplied 2026 CV, linked from the homepage.
- `robots.txt` — crawler access policy plus the sitemap URL.
- `sitemap.xml` — canonical homepage URL for search engines.

## Publish on GitHub Pages
1. Extract the ZIP and upload the **contents of this folder** to the root of `ShaidaMuhammad.github.io`.
2. Keep the `images` folder as a folder, and keep the PDF, `index.html`, `robots.txt`, and `sitemap.xml` together in the publishing root.
3. In GitHub, open **Settings → Pages** and ensure the publishing source matches the branch and root folder where these files were uploaded.
4. The canonical website URL in this package is `https://shaidamuhammad.github.io/`.
5. Once published, add the site in Google Search Console and Bing Webmaster Tools, then submit `https://shaidamuhammad.github.io/sitemap.xml` and request indexing.

## SEO and publication status notes
The site includes a descriptive page title and meta description, canonical URL, Open Graph/Twitter metadata, meaningful heading structure, descriptive image alt text, and Schema.org Person structured data. Publication metadata links to publisher/conference sources where available. The ICAAD paper is labelled as accepted and scheduled for conference presentation; it is not described as already published. The concrete-strength research item is listed as a published Springer book chapter with links to both its chapter page and the book page.

Search engines decide whether and where to rank a page; these measures improve clarity and crawlability but cannot guarantee a top position. Consistent links from legitimate professional profiles, project repositories, and author pages can help establish identity and discovery.
